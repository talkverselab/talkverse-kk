# 카자흐어 절벽구간 v1 (2026-11-08)

- 말뭉치: 공개 자막 묶음의 카자흐어 판 167편(작품당 1판), 59.6만 토큰. 키릴 2,000자 미만·카자흐어 고유 글자 비율 3% 미만인 판은 뺐다. 대부분 번역 자막(카자흐스탄 제작 작품 대사 자료가 적음). 공개 저장소라 제공처 이름은 적지 않는다.
- 단위: 형태소 분석기로 낱말 = 기본형 하나(동사는 사전형 -у) + 굴절 접사 하나하나(복수·소유·격·부정·시제·인칭·부동사·분사·동명사)를 각각 한 토큰. 접사 토큰이 전체의 39.3%.
- 구간(누적 55·60·70·80% 에 처음 닿는 순위): **R1 = 45위(55.3%) · R2 = 62위(60.1%) · R3 = 160위(70.0%) · R4 = 477위(80.0%)**, 그 뒤 R5. 1,500위 누적 88.5% · 2,500위 91.7%.
- 몽골어(49·71·185·522, 1,500위 89.2%)와 거의 같은 모양.
- 한계: 분석기 기본형 오류(드문 동사의 사전형이 어긋남)·번역 자막의 외국 인명이 상위권에 섞임. 순위표 CSV 는 인명이 있어 저장소 밖 M6 `~/corpus/kk/out/lang_kk_top2500.csv` 에 둔다.
- 재현: `~/.venvs/kk-corpus/bin/python tools/corpus/cliff_kk.py <카자흐어 자막 zip> <출력 폴더> <분석기 모델 폴더>` (zip·모델은 M6 `~/corpus/kk/`).
- 앱 경계는 `app/lib/core/cliff.dart` 한 곳.
