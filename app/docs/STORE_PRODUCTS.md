# 스토어 상품 등록 목록 — 카자흐어유니버스 (2026-11-09 최종 가격)

가격 = `~/talkverse/PRICING.md`(사용자 최종 확정 2026-11-09)의 **앱 정가 / 앱 할인가**. 등록은 사용자가 App Store Connect·Google Play Console 에서 한다. 출시는 한자앱 → 완성된 언어앱부터 하나씩(uk 공지) — 카자흐어는 콘텐츠가 비어 있어 아직 아님.

스토어 판매가 = **할인가**(출시 기념·정기 할인 30%). 앱 결제 시트는 정가를 취소선으로, 스토어 가격을 크게(`lib/main.dart` `Purchase.configure`, `lib/screens/paywall_screen.dart`). 정가 기간에는 스토어 가격을 정가로 올리고 앱의 `krw` 도 정가로. 앱 안에서 사이트 가격을 안내하지 않는다.

- App Store Connect: 구독 3개는 구독 그룹 「카자흐어유니버스」. `all_*` 등록 방식은 uk 와 맞춘다. 이용약관 https://talkverse.uk/terms/ · 개인정보처리방침 https://talkverse.uk/talkverse/kk/privacy/

- 서버 `/me/purchases` 가 새 ID 를 인정해야 한다(uk). 앱은 구독을 「구매 시각 + 기간 + 3일」까지 열고 계정 이용권(`Account.has('kk')`)을 최종으로 본다.
