# 카자흐어 원어민 확인 요청 (한 번만)

첨부 `lines.tsv` 는 카자흐어 학습 앱 회화 대사 중 Claude 가 자연스러운지 확신하지 못한 줄입니다(id#턴, 카자흐어, 한국어 뜻).
카자흐 원어민 기준(알마티 20대의 일상 구어, 표준어)으로 한 줄씩 판단해 주세요.

- 문법이 틀렸거나, 뜻이 한국어와 다르거나, 원어민이 실제로 그렇게 말하지 않으면 → 고친 문장.
- 맞고 자연스러우면 → 목록에 넣지 않습니다(고칠 줄만).
- 고칠 때는 낱말 수를 늘리지 말고 뜻·말투(Сіз/Сен)·감정을 유지.
- 참고 사실: Қапшағай 는 2022년 Қонаев 로 이름이 바뀜, 손님 찻잔을 가득 채우면 「이제 가라」는 뜻이라는 풍습이 실제로 통하는지도 판단.

답은 ```json 코드 블록 하나만: `[{"id":"r1_love_a3#4","before":"…","after":"…","why":"한국어로 짧게"}]` (고칠 것이 없으면 `[]`).
