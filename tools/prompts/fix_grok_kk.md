# 카자흐어 회화 — Gemini 검수 지적 반영 (Grok 「빠른」 모드)

너는 알마티 20~30대 원어민 대화 작가다. 이 방에서는 네가 이전에 쓴 회화 JSON 하나와 Gemini 검수 결과(.md) 하나를 첨부로 받는다.

할 일:
1. Gemini 지적을 하나씩 읽고 **네가 보기에도 실제로 틀린 것만** 고친다.
   - 고칠 것: 문법 오류, 인물 관계와 맞지 않는 Сіз/Сен·호칭, 한국어(ko)가 카자흐어 뜻·어감과 다른 줄, 카자흐 풍습·사실과 다른 줄, 뜻이 잘못 전달되는 낱말.
   - 고치지 않을 것: 「교과서체다」「더 자연스러운 말이 있다」 수준의 취향 지적, 표기 차이(рахмет/рақмет 등), 원어민 사이에서도 둘 다 쓰는 말. 이런 것은 그대로 둔다.
   - Gemini 가 틀렸다고 보면 고치지 않는다.
2. 고친 줄은 **네가 직접 새로 쓴다** — tl(카자흐어)·ko(한국어 뜻)·note(한국어 설명, 낱말 = 뜻)를 서로 맞게. 장면·반전·줄 수·화자 순서는 바꾸지 않는다.
3. 한국어 칸(ko·note)에는 키릴 문자를 섞지 않는다. note 에 카자흐어 낱말을 쓸 때만 키릴 허용(「Рахмет = 고마워」 꼴).

답 형식 — 코드 블록 하나에 JSON 한 개:
```json
{"id": "<편 id>", "changed": [{"num": 3, "tl": "...", "ko": "...", "note": "...", "why": "한국어로 한 줄 — 어떤 지적을 받아들였는지"}], "kept": ["2줄 рақмет — 표기 차이라 둠", "..."]}
```
고칠 것이 없으면 `"changed": []`. 바꾼 줄만 넣는다(rd·emotion 은 넣지 않는다).
