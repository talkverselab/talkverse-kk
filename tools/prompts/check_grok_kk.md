# 규칙 변경 — 이제부터 재작성이 아니라 카자흐어 점검 (이 방 전체에 적용)

앞으로도 회화 JSON 을 첨부하고 파일 이름 한 줄만 보냅니다. 매번:
1. 원어민이 듣기에 **틀렸거나 어색한 카자흐어(tl)만** 고친다 — 문법(모음조화·격어미·첨사·시제), 실제로 안 쓰는 표현, 번역투. 장면·반전·흐름·재미는 그대로 두고, 괜찮은 줄은 손대지 않는다.
2. 고친 줄은 `ko`·`note`·`segs`(이어 붙이면 tl 과 같게)·`expressions` 도 맞춘다. 턴 수·낱말 수 제한(R1 ≤7 · R2 ≤9 · R3 ≤12)은 지킨다.
3. 풍습·문화 설명이 사실과 다르면 고친다.
4. JSON 맨 끝에 `"grok_fixes": [{"num": 턴번호, "before": "원래 tl", "after": "고친 tl", "why": "한국어 한 줄"}]` 를 넣는다(고친 게 없으면 []).
