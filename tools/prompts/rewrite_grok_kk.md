# 카자흐어 학습 회화 재작성 규칙 (이 방 전체에 적용)

앞으로 이 방에는 회화 JSON 파일 하나를 첨부하고 **파일 이름 한 줄만** 보냅니다. 매번 이 규칙대로 그 회화를 재작성해서 **JSON 전체를 ```json 코드 블록 하나로만** 답하세요(설명·인사 없이).

## 가장 중요
1. **일상 회화가 먼저**: 장면(가게·카페·길·버스·집·학교·직장·전화·메신저)에서 실제로 오가는 흔한 표현이 중심.
2. **반전·러브·플러팅은 그 일상 흐름 안에서 터지게**: 카오스는 「현실에서 있을 법하게 커지는 꼬임」, 비현실적 소동·판타지 금지. 연애 편은 심쿵 한 줄(마음을 들키는 말·말끝 흐리기·여운).
3. **원어민이 실제로 하는 짧은 구어 카자흐어**(표준어, 키릴). 문법(모음조화·격어미·의문 첨사)이 정확할 것. 교과서체·번역투·설명 대사 금지. 입에 남는 한 줄 + 웃긴 킥.
4. **모든 줄을 새로 쓴다**(그대로 두지 말 것). 장면·인물·반전 유형(twist_type)은 유지하되 더 재미있고 자연스럽게.

## 지킬 형식
- 칸 이름과 구조는 그대로. `id region island kind speakers twist_type draft` 는 바꾸지 않는다. `twist` 는 새 반전 턴 번호.
- 턴 수: R1 6~8 · R2 8~12 · R3 12~16. 한 턴 낱말 수: R1 ≤7 · R2 ≤9 · R3 ≤12.
- 턴 칸: `num speaker tl(카자흐어) rd("" 로 비움) ko(자연스러운 한국어, 같은 말투) note(「카자흐어 = 뜻」 한 줄) tags[] new[] emotion`.
- `emotion` 은 줄마다: neutral polite stiff cheerful amused teasing excited surprised shout tsukkomi annoyed sad worried flustered shy gentle 중 하나(neutral 은 절반 미만). 한 줄 안에서 감정이 바뀌면 `segs: [[감정, 본문], …]`(이어 붙이면 tl 과 같게).
- `expressions` 에는 실제로 쓴 일상 표현 2개 이상(Иә, Жоқ, Жарайды, Рахмет, Кешіріңіз, Сәлем, Қалайсың, Шынымен бе, Ойбай, Қап, Әрине, Қанша тұрады, Бір минут, Не болды 같은 것 — 대사에 그대로 들어 있어야 함).
- 말투: 처음 보는 사이·가게·일 = Сіз, 친구·연인 = Сен. A 는 학습자 `{name}` — 성별이 드러나지 않게(한국어에 오빠·누나·형·언니 금지).
- 실존 가게·브랜드·인물 이름 금지. 시각·숫자는 글자로(예: «бесте»).
